# FocusNotes 微信登录与云同步接入指南

本项目已定义微信登录、云同步、云端 AI 识别的**可替换接口**，当前三者均未接入；未配置时调用会抛出 `IntegrationRequiredError`，不会伪造登录或同步状态。本文说明每个接口的位置、需要准备的资质，以及接入步骤。

## 一、接口代码位置（都在仓库内）

| 能力 | 接口定义 | 实现位置 | 说明 |
| --- | --- | --- | --- |
| 微信登录 | `WeChatAuthProvider` | `packages/core/src/integrations.ts` | `signIn()` / `signOut()` / `restoreSession()`，返回 `UserSession`（userId / displayName / accessToken / expiresAt） |
| 云同步 | `CloudSyncProvider` | `packages/core/src/integrations.ts` | `push(userId, changes)` 推送本地变更；`pull(userId, sinceRevision)` 拉取云端增量 |
| 同步合并规则 | `mergeSyncedTodos()` | `packages/core/src/sync.ts` | 按修订号（revision）+ 更新时间取胜者，双端复用、已含单元测试 |
| 云端 AI 识别 | `SmartParserProvider` | `packages/core/src/integrations.ts` | 构造 `HybridSmartParser` 时传入 `SmartParserProvider` 则优先走云端，失败自动回退本地识别；当前 UI 未传入，始终使用本地识别 |
| 接口注册表 | `IntegrationRegistry` | `packages/core/src/integrations.ts` | 接入时在 `apps/desktop/src/main.tsx`、`apps/mobile/index.js` 启动入口注入实现（当前尚未注入） |
| 未接入占位 | `UnconfiguredWeChatAuth` | `packages/core/src/integrations.ts` | 当前默认实现，调用即抛 `IntegrationRequiredError` |

## 二、配置入口

- 桌面端：`apps/desktop/.env.example` → `VITE_WECHAT_APP_ID`、`VITE_CLOUD_API_URL`
- 移动端：`apps/mobile/.env.example` → `WECHAT_APP_ID`、`CLOUD_API_URL`
- 复制为 `.env` 并填写后，再实现对应的 Provider。

## 三、需要准备的资质（微信侧）

1. **微信开放平台**（https://open.weixin.qq.com）企业开发者账号。
2. 桌面端（Windows）走「网站应用」类型：开通「微信登录」能力，获得 `AppID` / `AppSecret`，PC 端展示二维码使用
   `https://open.weixin.qq.com/connect/qrconnect?appid=…&redirect_uri=…&response_type=code&scope=snsapi_login`，
   用户扫码回调拿到 `code` 后，**由你自己的后端**调用
   `https://api.weixin.qq.com/sns/oauth2/access_token?appid=…&secret=…&code=…&grant_type=authorization_code`
   换取 openid，并签发本项目定义的 `UserSession`。AppSecret 绝不能放进客户端。
3. 移动端（Android）走「移动应用」类型：同样需要 `AppID` / `AppSecret`，并在微信开放平台填写应用包名
   `com.focusnotes` 与签名摘要；客户端用微信 OpenSDK 拉起授权，`code` 仍交由后端换 `UserSession`。

## 四、云端需要自建的服务

1. **认证接口**：接收微信 `code`，换取并返回 `UserSession`（对应 `WeChatAuthProvider.signIn()`）。
2. **同步接口**：
   - `POST /sync/push`：接收 `{ userId, changes: TodoItem[] }`，按 `revision` 递增存储；
   - `GET /sync/pull?sinceRevision=N`：返回该用户修订号之后的增量（对应 `CloudSyncProvider`）。
3. **可选 AI 接口**：`POST /ai/parse` 接收自然语言，返回 `ParsedTodoDraft`（对应 `SmartParserProvider`，本项目
   `LocalSmartParser` 已可作为离线兜底）。
4. 数据模型与合并规则直接复用 `packages/core` 中的 `TodoItem` 与 `mergeSyncedTodos`，保证双端一致。

## 五、接入步骤（代码侧）

1. 在桌面端新建 `src/wechat.ts`，实现 `WeChatAuthProvider`（Electron 主进程打开二维码窗口，拿到 code 后请求你的后端）。
2. 在移动端新建 `src/wechat.ts`，接入微信 OpenSDK Android 版实现同一接口。
3. 两端分别实现 `CloudSyncProvider`（调用 `/sync/push` 与 `/sync/pull`，用 `mergeSyncedTodos` 合并后写回 `TodoStore`）。
4. 启动时用 `new IntegrationRegistry(weChatAuth, cloudSync)` 注入；如需在界面展示接入状态，读取
   `IntegrationRegistry.status()`（当前返回 `unconfigured` 或 `ready`）。
